# 新北市補助資訊專區

這是一個純 HTML、CSS、JavaScript 製作的靜態網站範本，可直接在電腦預覽，也適合部署到 GitHub Pages。

## 檔案內容

- `index.html`：網站主頁
- `style.css`：網站版面與美化
- `script.js`：手機選單、FAQ 展開與回到頁首功能
- `README.md`：使用說明

## 在電腦預覽

1. 解壓縮 ZIP。
2. 開啟 `ntpc_subsidy_site` 資料夾。
3. 雙擊 `index.html` 即可預覽。

## 上傳 GitHub Pages

1. 在 GitHub 建立 Repository。
2. 將解壓縮後的四個檔案上傳到 Repository 最外層。
3. 前往 **Settings → Pages**。
4. Source 選擇 **Deploy from a branch**。
5. Branch 選擇 `main`，資料夾選擇 `/ (root)`，再按 Save。

請勿只上傳 ZIP；GitHub Pages 必須直接讀取 `index.html`。
